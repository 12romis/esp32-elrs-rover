# Кореневий сертифікат сервера

Покладіть сюди файл `root_ca.pem` — кореневий сертифікат власника, яким підписано сертифікат MQTT-сервера (ADR-0006).
Він публічний за природою і може лежати в репозиторії (`.gitignore` робить виняток для цього файлу).
Без файлу збірка проходить, а передача вимкнена: дані не надсилаються без перевірки сертифіката сервера.
Після появи чи заміни файлу виконайте повну очистку збірки (`idf.py fullclean`), щоб CMake підхопив його.
