## Прапорці й припущення

- Відповідь `disarm` у FAILSAFE з поясненням за причиною — виведення контракту (medium): spec вимагає, щоб консоль пояснювала, але не каже, якою командою; `disarm` — природне місце, бо саме ним Розробник пробує «вийти». Ветується на `tasks`.
- Окремий клас «drive в ARMED з пульта» не введено: такий стан можливий лише в режимі «пульт», тож його покриває клас 3.
- Лінтера для текстового контракту немає (`spectral` не застосовується).

Підсумок: 4 з 4 перевірок ✓, core-знахідок немає, 1 прапорець (medium).
