## Прапорці й припущення

- Літерали `on`/`off` і назви каналів `head`/`red`/`green` — припущення (spec задає зміст, не слова); ветуються в журналі припущень design/api.
- Перевірка довжини числа (більше п'яти цифр для частоти чи чотирьох для тривалості читається як «поза діапазоном», без переповнення) — деталь реалізації, уточнить `tasks`.
- Лінтера для текстового контракту немає (`spectral` не застосовується).
