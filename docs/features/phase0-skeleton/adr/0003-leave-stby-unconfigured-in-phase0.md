# 0003 — Лишити лінію STBY неналаштованою у фазі 0

- **Status:** Accepted
- **Date:** 2026-10-17
- **Deciders:** Розробник проєкту + Claude (рішення прийняте в сесії clarify 2026-10-17 і внесене в spec §1; тут зафіксоване як архітектурне, з альтернативою, яку розглядали тоді)

## Context

Документ 02 §4.5 вимагає опускати STBY (GPIO21) у 0 при кожному переході в DISARMED, FAILSAFE чи FAULT. Фаза 0 входить у DISARMED, але мотори не підключені, а правила пунктів 7 і 12 конституції забороняють підіймати STBY до прозвонювання шлейфів. NFR специфікації вимагає «0 ліній ШІМ/напрямку/STBY налаштовано як виходи». Лінія тримається низькою апаратною притяжкою R16 (10 кОм до GND).

## Decision drivers

- AC-07 і NFR «Безпека виходів» (0 ліній налаштовано як виходи, STBY низький 100 % часу).
- Пункт 12 конституції: до прозвонювання шлейфів прошивка не подає ШІМ і не піднімає STBY.
- Документ 02 §4.5 (вимога опускати STBY) діє для фаз з керуванням моторами.

## Considered options

1. **Не чіпати лінію** — STBY неналаштований, низький лише завдяки R16; виконання §4.5 переходить у фазу 1.
2. **Налаштувати як вихід = 0 при вході в DISARMED** — виконує §4.5 буквально, але порушує NFR фази 0 і створює в коді місце, звідки лінію можна підняти.

## Decision outcome

**Chosen:** варіант 1. Фаза 0 є явним винятком із §4.5; код фази 0 не посилається на `PIN_STBY`, не викликає конфігурацію GPIO для ліній мотора. У фазі 1 `drive` бере на себе §4.5 і додає опускання STBY у DISARMED/FAILSAFE/FAULT.

## Consequences

**Positive**
- Фаза 0 фізично не може підняти STBY: немає коду, який налаштовує лінію.
- Перевірка проста: огляд коду + мультиметр на STBY.

**Negative**
- Безпека залежить від апаратної притяжки R16, а не від коду; якщо R16 не змонтований або пошкоджений, програма цього не виявить.
- У фазі 1 потрібен окремий пункт у специфікації, щоб виняток не став постійним.

**Neutral**
- Виняток діє лише до завершення фази 1; FAILSAFE і FAULT у фазі 0 недосяжні на залізі.
