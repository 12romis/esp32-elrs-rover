# 0002 — Stop by coasting with outputs off before state write

- **Status:** Accepted
- **Date:** 2026-10-18
- **Deciders:** Архітектор + Розробник (відповідь на clarify, 2026-10-18)

## Context

Документ 02, §6.3, пише для FAILSAFE «STBY=0, гальмування», але за §2.3 при низькій STBY виходи драйвера у вільному стані, тож гальмування замиканням обмоток (DIR 1/1) і низька STBY не поєднуються. Розбіжність у документі озвучено (конституція, п. 1). Потрібен один спосіб зупинки для роззброєння, спливання вікна команди й відсічки, а також порядок «вимкнути виходи — записати стан».

## Decision drivers

- STBY піднята лише в ARMED, ШІМ ненульовий лише в ARMED (конституція, п. 7; spec AC-08, AC-20).
- Тривалість короткого гальмування була б новим невиміряним числом, а пункт 3 конституції забороняє його вигадувати.
- Жоден момент у стані, відмінному від ARMED, не має лишати виходи ввімкненими (spec AC-08).

## Considered options

1. **Вибіг:** ШІМ 0, обидві лінії DIR низькі, STBY низька; виходи записуються до зміни стану.
2. **Коротке гальмування, потім STBY вниз:** DIR 1/1 на певний час, потім STBY низька (розглянуто на clarify і відхилено Розробником).

## Decision outcome

**Chosen:** Option 1. Зупинка — це послідовність у `drive_core`: нульовий ШІМ, DIR 0/0, STBY низька, і лише після цього `control` запитує перехід у новий стан. Ті самі рівні тримаються в кожному такті, коли стан не ARMED. Варіант 2 потребує числа, якого немає в `docs/measured.md`;.

## Consequences

**Positive**
- Одне правило для всіх шляхів зупинки; інваріант «вимкнено поза ARMED» перевіряється хостовим тестом.
- Немає нового вигаданого числа.

**Negative**
- Колеса зупиняються вибігом, довше, ніж при гальмуванні.

**Neutral**
- Якщо пізніше знадобиться гальмування, воно додається в `drive_core` разом із виміряною тривалістю; розбіжність §6.3 документа 02 варто виправити в документі (рішення Розробника).
