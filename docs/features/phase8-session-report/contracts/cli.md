# Контракт консолі та зовнішніх інтерфейсів — phase8-session-report

> Інтерфейс: текстова консоль через USB-Serial-JTAG (`target_surfaces: [cli]`, прочитано з sad.md). Контракт **виведено** зі spec §5 (AC-01…AC-09, AC-17, AC-19, AC-23, AC-24), sad.md §5 і §6 (потоки 5–8), spec A1–A4, A16, A19. Окремо описано два нестандартні інтерфейси цієї фази: канал пульта CH9 і колір індикатора плати. Документ звіту й MQTT-подія — у `events.md`.

Загальне — без змін відносно фаз 0–7: рядок до 64 символів, завершення CR, LF чи CR LF, слова через пробіл, регістр має значення, коду завершення немає. Терміни — `CONTEXT.md` (Режим контролю перешкод, Сесія, Звіт сесії, Черга звітів, Індикатор плати, Утримання перед перешкодою).

## Нова команда `report`

| Форма | Дія | Джерело |
|---|---|---|
| `report` | друкує стан звітів; у DISARMED запускає спробу передачі негайно | spec A16, AC-17; sad.md потік 8 |

Будь-яка інша форма (будь-який аргумент) — клас «зайві аргументи»; нічого не змінюється, відповідь веде до `help`.

### Відповідь `report`

Порядок рядків фіксований: стан, потім результат дії.

| Рядок | Поля | Формат | Джерело |
|---|---|---|---|
| стан черги | скільки звітів у черзі (0…2); для кожного номер сесії й причина завершення | ціле; `seq`, текст | spec A17; sad.md §5 |
| режим | режим контролю перешкод (увімкнено/вимкнено) і чи значення за замовчуванням | текст | spec A1, AC-04 |
| мережа | налаштування мережі «задано / не задано»; результат останньої спроби (ок, немає мережі, сертифікат не довірений, немає підтвердження, перервано озброєнням, не було спроб) і час мс від старту | текст; ціле | spec A15, A19, AC-14, AC-22 |
| результат команди | лише в DISARMED із непорожньою чергою й заданими налаштуваннями: «спробу запущено» і потім рядок результату | текст | sad.md потік 8 |

Паролі й SSID **ніколи** не друкуються — лише «задано / не задано» (spec AC-23, A19).

### Права за станом

| Ситуація | Що робить `report` | Джерело |
|---|---|---|
| DISARMED, черга непорожня, налаштування задані | показує стан і запускає спробу з власним лімітом 30 с від моменту команди | spec A16 |
| DISARMED, спроба вже триває | показує стан і пише «передача вже триває»; другу спробу не запускає | spec clarify, A16 |
| DISARMED, черга порожня | показує стан і пише «нічого надсилати»; Wi-Fi не вмикає | spec clarify |
| DISARMED, налаштувань немає | показує стан і пише «налаштування мережі не задано, передача не починається» | spec AC-24 |
| ARMED, OBSTACLE_HOLD, FAILSAFE | показує стан черги; передачу не запускає й пояснює, що вона можлива лише в DISARMED | spec AC-17 |
| BOOT, SELFTEST, FAULT | показує стан черги; передача відхиляється з тим самим поясненням | spec A13 |

| Команда | BOOT | SELFTEST | DISARMED | ARMED | OBSTACLE_HOLD | FAILSAFE | FAULT |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| `report` (показ) | так | так | так | так | так | так | так |
| `report` (спроба) | ні | ні | так | ні | ні | ні | ні |

## `status`: нові поля

| Поле | Значення | Джерело |
|---|---|---|
| контроль перешкод | «увімкнено» / «вимкнено»; для увімкненого за замовчуванням — «(за замовчуванням, пульт не підтвердив)»; «охороняє» / «не охороняє» (жоден далекомір не працює чи знімок застарів) | spec A1, A3, AC-04, AC-07 |
| звіти | кількість у черзі, результат останньої спроби, налаштування «задано / не задано», стан радіо «вимкнено» / «спроба триває» | spec A13, A15, A19 |

Решта полів фаз 0–7 без змін. Колонка «Wi-Fi» у виводі не друкує SSID чи паролі.

## Рядки журналу (події)

| Подія | Рядок називає | Скільки разів | Джерело |
|---|---|---|---|
| вхід в OBSTACLE_HOLD (існує з фази 6, змінено) | сектор, і **кожен** датчик сектора нижче порога `TOF_OBSTACLE_MM` з відстанню; якщо зайняті обидва сектори — датчики обох із позначкою сектора; несправний датчик не називається | один на вхід в утримання; зміна складу датчиків усередині утримання нового рядка не дає | spec A4, AC-08, AC-09; sad.md потік 7 |
| зміна режиму контролю | «контроль перешкод вимкнено» / «ввімкнено» | один на зміну | spec AC-01 |
| втрата охорони | «захист від зіткнень не діє» | один на перехід «охороняє → не охороняє» | spec A3, AC-07 |
| відновлення охорони | «захист відновлено» | один на перехід назад | spec A3 |
| сесія завершена | номер сесії, причина завершення | один на сесію | spec A5, A6 |
| звіт у черзі видалено | «видалено найстарший звіт, сесія N» | один на витіснення | spec AC-15 |
| результат спроби | доставлено, або причина невдачі (немає мережі, сертифікат не довірений, немає підтвердження, перервано озброєнням) | один на спробу | spec AC-10, AC-14, AC-18, AC-22 |
| немає налаштувань мережі | «налаштування мережі не задано, передача не починається» | один на кожен вхід у DISARMED із непорожньою чергою | spec AC-24, clarify |

Пароль не з'являється в жодному рядку (spec AC-23).

## `help`

Додається рядок `report` — стан звітів і негайна передача (лише DISARMED).

## Канал пульта CH9 (зовнішній інтерфейс)

| Поле | Значення | Джерело |
|---|---|---|
| Канал | CH9 (індекс 8) у кадрі каналів CRSF | spec A1 |
| Інтерпретація | значення вище середини (> 992, як у тумблера озброєння) — «контроль увімкнено»; інакше «вимкнено» | spec A1 |
| За замовчуванням | «увімкнено»: від старту плати, у стендовому режимі, при втраті зв'язку, доки не прийде новий кадр | spec A1, AC-04 |
| Налаштування TX12 | на канал CH9 у мікшері EdgeTX виводиться вибраний тумблер (SB/SC/SE/SF); два положення Розробник записує в `docs/measured.md` (OQ-6) | spec OQ-6 |
| Зміна | у будь-якому стані автомата; не впливає на інваріанти безпеки | spec A2, AC-03 |

Примітка: поки перемикач не виведено в мікшері, CH9 стоїть у спокої на 992 і вимикає захист (значення не вище середини) — див. sad.md §11.

## Індикатор плати (зовнішній інтерфейс)

| Стан і умова | Колір | Джерело |
|---|---|---|
| FAILSAFE | червоний | phase7 A8; spec A3 |
| OBSTACLE_HOLD | жовтий | phase7 A8; spec A3 |
| DISARMED або ARMED, контроль ввімкнено, хоч один сектор охороняється | зелений (зелений канал, рівень 40, порядок байтів GRB із P8) | spec A3, AC-05 |
| DISARMED або ARMED, контроль вимкнено | погашений | spec AC-05 |
| DISARMED або ARMED, контроль ввімкнено, жоден далекомір не працює | погашений (+ рядок журналу «захист не діє») | spec AC-07 |
| BOOT, SELFTEST, FAULT | погашений | spec A3 |

Пріоритет: червоний > жовтий > зелений (spec AC-06). Реакція на тумблер ≤ 200 мс (spec §6).

## Що не змінюється

`arm`, `disarm`, `drive`, `light`, `beep`, `enc`, `pid`, `tof`, `reboot`, `wdt_test` і матриця прав фаз 0–7 — без змін. Командою консолі режим контролю не міняється (spec §3).
