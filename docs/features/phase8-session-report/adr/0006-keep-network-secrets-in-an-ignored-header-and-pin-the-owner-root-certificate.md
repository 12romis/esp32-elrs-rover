# 0006 — Keep network secrets in an ignored header and pin the owner root certificate

- **Status:** Accepted
- **Date:** 2026-10-22
- **Deciders:** Розробник, Агент (design, рівень easy)

## Context

Spec A15, A19, §6.1: SSID і пароль Wi-Fi, облікові дані сервера лише в локальному файлі поза git; сервер перевіряється власним кореневим сертифікатом; збірка без файлу не ламається, а передача вимикається. Рішення Розробника (2026-10-22): «локальний файл поза git».

## Decision drivers

- Нуль входжень паролів у git, консоль, журнал, `status`, звіт (spec §6).
- Збірка без секретів проходить без помилок і нових попереджень (п. 8; spec AC-24).
- Корінь довіри не залежить від публічних центрів сертифікації.

## Considered options

1. **`components/report/report_secrets.h` (у `.gitignore`) + шаблон `report_secrets.example.h` у репозиторії; кореневий сертифікат `certs/root_ca.pem` вбудовується в образ; `__has_include` і умова в CMake вимикають передачу, якщо файлів немає.**
2. **Окремий розділ флешу з файлом налаштувань, що прошивається окремо від застосунку** — пароль можна змінити без перезбірки застосунку, але потрібна нова таблиця розділів і окремий крок прошивки.
3. **Параметри в `sdkconfig`/Kconfig** — пароль потрапляє в згенерований `sdkconfig`, який легко закомітити випадково, і в захищений `sdkconfig.defaults`.

## Decision outcome

**Chosen:** варіант 1. Пароль ніколи не виводиться: `status` і команда `report` показують «задано / не задано». Сертифікат перевіряється за вбудованим коренем і ім'ям сервера; без перевірки дані не надсилаються (spec AC-22). Кореневий сертифікат публічний за природою, тож може лежати в репозиторії; його файл надає Розробник (OQ-2).

## Consequences

**Positive**
- Секрети поза git; збірка без них працює, передача вимкнена з одним поясненням.
- Сертифікат закріплено: підміна сервера не проходить.

**Negative**
- Зміна пароля вимагає перезбірки й прошивки; пароль зберігається у флеші в образі.
- Потрібна дисципліна `.gitignore` (перевіряється хостовим скриптом, як `check_protected.sh`).

**Neutral**
- Перехід до зберігання в NVS пізніше змінює лише `report_hal`.
