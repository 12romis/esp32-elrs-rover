# 0002 — Implement a minimal MQTT 3.1.1 publisher in report core over esp-tls

- **Status:** Accepted
- **Date:** 2026-10-22
- **Deciders:** Розробник, Агент (design, рівень easy)

## Context

Звіт іде на MQTT-сервер із перевіркою власного кореневого сертифіката (spec A15, OQ-2). У дереві IDF 6.1 бібліотеки esp-mqtt немає (`components/` має `esp_wifi`, `lwip`, `mbedtls`, `esp-tls`, `tcp_transport`); вона доступна лише як керований компонент із реєстру. Звіт один на сесію, лише відправка (spec §3: вхідного каналу немає).

## Decision drivers

- Конституція, п. 6: кодування й розбір пакетів у `*_core.c` без заголовків ESP-IDF, покриття хостовими тестами.
- Збірка не повинна залежати від мережі й реєстру; меншого розміру образ (app-розділ 1 МБ, spec A22).
- Потрібні лише CONNECT, PUBLISH з підтвердженням, DISCONNECT (доставка «принаймні раз», OQ-4).

## Considered options

1. **Власний мінімальний MQTT 3.1.1 у `report_core` поверх `esp-tls`** — пакети CONNECT, PUBLISH (QoS 1), PUBACK, DISCONNECT; транспорт і TLS у `report_hal`.
2. **esp-mqtt з реєстру компонентів** — готова бібліотека з ретраями й усіма рівнями QoS; потребує `idf_component.yml`, мережі під час першої збірки, логіка її не покривається хостовими тестами.

## Decision outcome

**Chosen:** варіант 1 (рішення Розробника, 2026-10-22). Кодер/розбірник пакетів — чисті функції, перевіряються хостовими тестами на еталонних байтах; HAL лише відкриває TLS-зʼєднання, пише й читає байти з таймаутом 100 мс на крок (щоб `report` перевіряв стан не рідше ніж раз на 100 мс). Топік `rover/<mac>/session`, QoS 1, `retain` вимкнено, client id `rover-<mac>`, чиста сесія, keepalive не потрібен (зʼєднання коротке); номер сесії у документі відсікає дублікати (spec A12, A17).

## Consequences

**Positive**
- Збірка автономна; логіка пакетів покрита хостовими тестами.
- Менший образ, повний контроль над таймаутами й перериванням.

**Negative**
- ~150 рядків власного коду, який треба підтримувати; не підтримуються підписка, ретрани, QoS 2, MQTT 5.
- Помилки сумісності з нестандартними серверами виявляться лише на залізі (приймання).

**Neutral**
- Перехід на esp-mqtt пізніше змінює лише `report_hal` (транспорт), а не формат звіту й чергу.
