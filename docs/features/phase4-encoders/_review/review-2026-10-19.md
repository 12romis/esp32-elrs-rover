## Findings

### F1 — [stage-2] Швидкість з приросту однієї вибірки, мінімального інтервалу немає

- **Де:** `components/encoders/encoders_core.c:143-156`, `components/encoders/encoders_hal.c:83`; spec §6 «Стабільність швидкості», AC-04, ADR-0001.
- **Суть:** після затримки задачі понад 20 мс `vTaskDelayUntil` наздоганяє — вибірки з `dt` ≈ 50 мкс; приріст 1 дає викид ≈ 433 об/хв, приріст 0 — хибний нуль. Рух із вибірки з `dt == 0` іде в накопичувач, але не у швидкість наступного інтервалу.
- **Пропозиція рецензента:** мінімальний `dt` інтервалу (параметр core); швидкість як `(accum − accum на мітці last_us) / dt`; хостовий тест на сплеск наздоганяння.
- **Verdict:** Fix now — задача-виправлення для `/sdd:implement` за пропозицією рецензента.

### F2 — [stage-1] Відмова `enc` не називає, що саме не так

- **Де:** `components/rover_console/console_core.c:190`; `contracts/cli.md:16`, AC-07.
- **Суть:** `enc foo`, `enc reset x`, `enc Reset` дають однаковий текст; контракт вимагає назвати причину (невідоме друге слово, помилка в `reset`, третє слово) і перелічити обидві форми.
- **Verdict:** Fix now (код) — розбір повертає причину за зразком `console_parse_beep` / `console_msg_beep_error`, тест у `test_console.c`; контракт без змін.

### F3 — [stage-1] `acceptance.md` не перевіряє AC-03 у стані FAILSAFE

- **Де:** `docs/features/phase4-encoders/acceptance.md:22,24`; AC-03.
- **Суть:** колеса крутять рукою лише в DISARMED (крок 2) і перевіряють знаки в ARMED (крок 4); FAILSAFE не покрито.
- **Verdict:** Fix now (документ) — додати крок: вимкнути пульт в ARMED → FAILSAFE, прокрутити колесо рукою, `enc` — лічильник змінився, `status` показує FAILSAFE.

### F4 — [stage-2] Хостовий прогін довший за NFR «≤ 5 с»

- **Де:** `docs/features/phase4-encoders/spec.md:201`, `test/host/run_tests.sh:23`; spec §6, QG-3 `sad.md`.
- **Суть:** прогін 6.1–6.2 с (8 ядер); на базі `2870d32` уже 5.36 с — порушення успадковане, фаза додала ≈ 0.8 с.
- **Verdict:** Defer — spec §8 OQ-2 (owner: Розробник, due: до `/sdd:specify` фази 5); факт часу прогону записати в `acceptance.md` разом із F3.

### F5 — [stage-2] Спільний стан утричі більший, ніж записано в SAD

- **Де:** `components/encoders/include/encoders_core.h:36` (`char reason[64]` у кожному колесі); `sad.md:116` («Знімок < 200 байтів, копіюється під `portMUX`»).
- **Суть:** `enc_state_t` ≈ 408 байтів (4 × 96 + 24) копіюється цілком під spinlock — розбіжність із записаним рішенням.
- **Verdict:** Fix now (код) — зберігати `esp_err_t` / код причини замість рядка, текст формувати при друку; знімок має вкластися в < 200 байтів за SAD.
