# api-sync-report — phase4-encoders (контракт консолі)

Форма контракту: `contracts/cli.md` (target_surfaces: `[cli]`, прочитано з sad.md, не виведено заново). `data-model.md` відсутній — **легальний пропуск** (зміни схеми немає: прошивка без сховища, стан енкодерів — у пам'яті; sad.md §6 «Схема даних не змінюється»). Подій для зовнішніх споживачів немає (`events.md` не потрібен: обмін між задачами `encoders` і консоллю — внутрішній, ADR-0001).

## Forward drift checklist

| Перевірка | Результат |
|---|---|
| Команда ↔ модель/схема | ✓ схеми немає; одна нова команда, синтаксис решти без змін |
| Клас відмови ↔ AC | ✓ «хибні аргументи» → AC-07; відмови за станом немає → матриця spec |
| Валідація ↔ обмеження | ✓ допустимі лише дві форми; числових аргументів немає |
| Контракт ↔ послідовності | ✓ потік 2 (знімок, обнулення з переліком недоступних), потік 4 (недоступне колесо, помилкова форма команди) |

## Back-feed (покриття)

| AC | Де в контракті |
|---|---|
| AC-01, AC-02, AC-03, AC-06 | відповідь `enc`: лічильник, оберти, швидкості, відстань, знак |
| AC-04, AC-05 | відповідь `enc` (лічильник і швидкість між знімками); заголовок — час для перевірки узгодженості |
| AC-07 | клас «хибні аргументи» |
| AC-08 | недоступне колесо в `enc`, `enc reset`, `status`; журнал старту |
| AC-09 | відповідь `enc reset`; матриця |
| AC-10, AC-11, AC-12 | не контракт (процес роботи Агента) |

Кожна операція мапиться на історію: `enc` — US-01, US-02, US-03, US-04; `enc reset` — US-02 (AC-09); помилкова форма і `status` — US-05. Жодної AC без місця в контракті й жодної операції без AC. **Прогалин у послідовностях немає.**

## Прапорці й припущення

- `enc reset`, коли жодне колесо не доступне — виведення контракту (medium); ветується на `tasks`.
- Число пар «команда × стан × режим» 140 (10 × 7 × 2) — арифметика контракту, у spec §6 такого рядка немає (фаза 3 мала 126); тест матриці на `tasks`.
- Лінтера для текстового контракту немає (`spectral` не застосовується).

Підсумок: 4 з 4 перевірок ✓, core-знахідок немає, 2 прапорці (medium, low).
