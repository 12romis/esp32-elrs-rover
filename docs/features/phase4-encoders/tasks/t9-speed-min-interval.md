# T9 — Швидкість лише за інтервал не коротший за половину номіналу (review F1)

## Source

Знахідка огляду `_review/review-2026-10-19.md`, F1 (verdict «Fix now»).

## What

Після затримки задачі понад 20 мс `vTaskDelayUntil` наздоганяє, і вибірки йдуть з `dt` у десятки мкс: швидкість з такої вибірки дає викид (1 імпульс за 50 мкс ≈ 433 об/хв) або хибний нуль. Рух із вибірки, що інтервалом не стала, не потрапляє в швидкість наступного інтервалу.

- Номінальний період вибірки `ENC_PERIOD_US` (20 000 мкс, sad.md §4) переїжджає в `encoders_core.h`; HAL бере період звідти. Мінімальний інтервал `ENC_MIN_INTERVAL_US` = половина номіналу.
- Вибірка з `dt < ENC_MIN_INTERVAL_US` накопичує рух у лічильник і в «рух інтервалу», але інтервалом не є: швидкість, мітка й лічильник інтервалів не змінюються.
- Швидкість інтервалу = весь рух від попередньої мітки / `dt`.

## Definition of Done

Хостові тести: сплеск наздоганяння (вибірки через 50 мкс після довгої паузи) не змінює швидкість; рух з короткої вибірки входить у швидкість наступного інтервалу; наявні тести швидкості зелені. Раннер зелений, `check_core_headers.sh` чистий, `idf.py build` без нових попереджень.
